# TDE FRONTEND

Trabalho da matéria FRONTEND do prof. Gean Trabuco.

## Sobre o projeto
Se trata de um projeto frontend estático com bootstrap, HTML e CSS.
É uma landing page de uma empresa de viagens/turismo.

## Tecnologias utilizadas
- __HTML5__ : para a estrutura do código
- __CSS3 e Bootstrap 5.3__ : estilização do projeto
